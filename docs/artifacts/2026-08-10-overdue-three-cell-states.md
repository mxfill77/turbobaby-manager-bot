# СКАН ПРОСРОЧЕК ЧИТАЕТ ТРИ СОСТОЯНИЯ КЛЕТКИ: «не измерено» перестало быть просрочкой

**Дата:** 10.08.2026 · **Полоса:** VPS · **Коммит:** см. §9 ·
**Основание:** контракт клетки `51c44cd` + выкладка моста `@79`
(`docs/artifacts/2026-08-10-bridge-cell-contract-deploy.md`), перепись
`docs/artifacts/2026-08-08-park-overdue-35-of-38-census.md`.

## 1. Премиса проверена ЖИВЬЁМ, а не по документу

ТЗ требовало первым делом убедиться, что мост с контрактом выложен: честный вид поверх слепого
источника хуже нынешнего вранья — скан начал бы говорить «не измерено» про всё подряд.

Артефакт выкладки утверждает `@79`, но утверждение документа фактом не является, поэтому снято
живое чтение (read-only, `_scratch_cellscan_0810/premise.py`):

```
ok: True | байков: 38 | с разметкой: 38
клеток ТО: 152 | исходы: {'ok': 97, 'empty': 49, 'mismatch': 6}
fleet() БЕЗ cells: байков 38 | с разметкой 0
```

Разметка есть у **38 из 38**; без просьбы её нет ни у одного — старые потребители не видят лишнего
байта. Премиса подтверждена, работа продолжена.

## 2. Что изменено

Одна строка держала весь класс (`splinter._o3_overdue_scan`, до правки):

```python
last = _i(b.get(f"{kind}_last_km")) or 0
if last <= 0:
    if cur >= int(interval):          # «не делалось» → в ТОТ ЖЕ список просрочек
        items.append({..., "nobase": True})
```

Пустая клетка, прочерк `-`, настоящий ноль и отрицательное приезжали от моста ОДНИМ нулём, и
различить их скан не мог в принципе. Теперь клетка судится контрактом `fleet_cell.read`:

| состояние клетки | исход скана | почему |
|---|---|---|
| ЗНАЧЕНИЕ, срок вышел | **просрочка** | есть от чего отсчитывать срок |
| ПУСТО | **не измерено** | мерить было нечего |
| НЕ-ЧИСЛО (`-`, слово, дата) | **не измерено** | содержимое есть, пробегом не стало |
| разметки нет (старый мост) | **не удалось проверить** | мы НЕ ЗНАЕМ, что в клетке |

`payload` скана стал словарём `{overdue, unmeasured, unchecked, impossible, counts}`; три числа
не сворачиваются одно в другое ни в скане, ни у доски, ни у владельца. Ветка `nobase` удалена
вместе со своим источником — в наряд неизмеренная клетка больше не попадает.

**Настоящий ноль остаётся просрочкой** и даёт те же числа, что давал `nobase` (`next = interval`):
замена БЫЛА, записана на нулевом пробеге. Но вслух названа невозможной (§5).

## 3. Замер: было 35 → стало 23, на ОДНОМ живом корпусе

Оба счёта прогнаны в одном заходе на одном ответе моста, с одними интервалами и одним текущим
пробегом (`_scratch_cellscan_0810/measure.py`) — расходится РОВНО толкование клетки:

```

    из них ТОЛЬКО из-за клетки без замера: 12 байков

(2) НОВЫЙ СЧЁТ: осмотрено 38 байков
    просрочено 23 байков (36 клеток) · не измерено 46 клеток у 29 байков ·
    не удалось проверить 0 клеток у 0 байков
    по регистрам:
      Масло          просрочено   5 · не измерено   0 · не удалось проверить   0
      Редуктор       просрочено  12 · не измерено   0 · не удалось проверить   0
      ABS            просрочено  16 · не измерено  18 · не удалось проверить   0
      Возд. фильтр   просрочено   3 · не измерено  28 · не удалось проверить   0
```

**35 → 23 — ровно встречное число переписи 08.08**, полученное независимо и на живых данных.
Ушли двенадцать поимённо: 5849, 798, 9011, 5580, 8949, 6895, 9315, 3902, 4725, 3503, 2478, 4724.

### Две разницы, которые надо объяснить, а не замолчать

**(а) ABS 16, а перепись предсказывала 14.** Разница ровно 2 — байки `8969` (ABS = −5000) и
`1813` (ABS = настоящий ноль). Перепись считала ВСЕ нули пустыми клетками и убирала их; контракт
показал, что это ЗНАЧЕНИЯ, а значит просрочки по ним законны. Оба названы в §5.

**(б) клеток без значения 55, а «не измерено» 46.** Разница 9 — пустые клетки редуктора у мото и
XADV, где вид не трекается вовсе (`interval is None`). Проверено отдельно
(`_scratch_cellscan_0810/verify_delta.py`): «нетрекаемых пустых клеток редуктора: 9 — это и есть
разница». Считать их «не измеренными» значило бы раздуть второе число на регистрах, которых у
байка нет.

## 4. Три числа владельцу — раздельно, с единицами

`splinter._o3_counts_line` (одна формулировка на всех потребителей):

```
просрочено 23 байков (36 клеток) · не измерено 46 клеток у 29 байков ·
не удалось проверить 0 клеток у 0 байков
```

Единица названа у каждого числа намеренно: просрочка исторически считалась ПО БАЙКАМ («35 из 38»),
а «не измерено» живёт ПО КЛЕТКАМ (у байка их до четырёх). Без единиц числа выглядели бы сравнимыми
и снова слиплись бы. Разложение по четырём регистрам — в `counts["by_kind"]`.

Куда попало: заголовок доски нарядов (RU+TH), дайджест владельца `devbot._g_overdue`, сводка
`/o3board` в `bot.py`.

## 6. «Решено» говорится только о решённом

Побочный дефект, который правка КЛАССА создала бы, если бы его не закрыть: двенадцать ушедших
байков на следующем синке доски получили бы «✅ решено, просрочек нет» — доска показала бы
починку там, где никто ничего не мерил. Теперь байк, ушедший из просрочек в «не измерено»,
получает «🔎 не измерено», и **msg_id за ним сохраняется**: вопрос не закрыт, он сменил вид.
Настоящая починка по-прежнему даёт «✅ решено» и забывает msg_id — ветка не ослаблена (регресс
`test_overdue_cells.py` §6 проверяет ОБА пути).

## 7. Тесты

**Новый файл `tests/test_overdue_cells.py` — 53 проверки, все зелёные.** Разметка в фикстурах
ДОСЛОВНО живого формата, снятого с прода этим заходом (`_scratch_cellscan_0810/cells_format.py`):
`{"state":"value","num":18302,"raw":"18302"}` · `{"state":"empty","raw":""}` ·
`{"state":"text","raw":"-"}`. Секции: три состояния → три исхода · три числа раздельно ·
невозможные значения (отрицательное, ноль, H > замены) названы и НЕ исправлены · **разметки нет →
всё в «не удалось проверить», ноль просрочек и ноль «не измерено»** (та самая ловушка из ТЗ) ·
голден класса «12 фантомов» · доска не лжёт «решено» · владелец видит три числа.

**Легаси-фикстуры догнаны до живого формата** (§8 свода среды: мок обязан повторять живой формат
запуска — иначе он проверяет несуществующий мост). До правки все четыре суита падали с
`fleet() got an unexpected keyword argument 'cells'`: `test_o3.py`, `test_scan_contract.py`,
`test_orchestrator_stage2.py`. Перевод однозначен: `0` в плоском поле означал «замену не делали» =
ПУСТАЯ клетка. Единственная правка ЗНАЧЕНИЯ — ABS у NMAX 4255 поднят с `0` до `5000` в трёх
файлах: предмет тех суитов — механика доски, зелёные команды и паритет RU/TH, и парк должен был
остаться просроченным по-настоящему. Смысл «пустая клетка ≠ просрочка» закреплён отдельным
файлом, а не спрятан в переписанных фикстурах.

Изменённые утверждения названы прямо: `«❗ не делалось»` в просрочках больше не появляется
(ветка удалена вместе с источником), `stats` доски проверяется по ключам, а не полным равенством
словаря (он законно вырос на второе и третье число).

## 9. Статус в проде — честно

**Технически готово, функционально в проде НЕ подтверждено.** Класс «фикс в git ≠ фикс в проде»
здесь **ДЕЙСТВУЕТ**: `_o3_overdue_scan` живёт в памяти процесса `splinter` (там же devbot и
`/o3board`), а рестарт сервиса этим заходом запрещён ТЗ («процессы не трогать без отдельного
разрешения»). До рестарта `splinter` живой бот продолжает считать по-старому — 35, с двенадцатью
фантомами. Числа §3 получены прогоном НОВОГО кода на ЖИВЫХ данных, а не наблюдением прода.

Чтобы правка поехала: `systemctl restart splinter` (оранжевый цикл, гейт уже зелёный).

## 10. Остатки

- **рестарт splinter не сделан** — см. §9, это решение владельца;
- **зеркало ПК-полосы не сделано**; точки касания: свой скан просрочек, если он там есть, и
  формат мока `fleet`;
- **`mileage` (кол.H) в невозможных значениях судится только когда H — ЗНАЧЕНИЕ**: пустая H
  сравнения не даёт вовсе (молчим, а не выдумываем);
- проверка «замена записана ПОЗЖЕ текущего пробега» (перепись §4г, байк 7532) **не заводилась** —
  ТЗ называло три вида невозможности, этот в них не входит;
- **«не измерено» на доску карточками не выносится** — только числом в заголовке: карточка есть
  наряд на работу, а неизмеренная клетка требует ЗАМЕРА, это другой вид действия;
- дробное значение клетки (`35200.5`) усекается `int()`; прежний `_i` на таком падал в `None` и
  отправлял клетку в «не делалось» — новое поведение честнее, но названо здесь, а не замолчано.
