### Почему это не мелочь

Чужая работа — из версии **@77 с описанием «ВРЕМЕННЫЙ 30.07 … снять после»**: её автор
сам пометил её как временную и в прод не выкладывал. Выкатка сделала бы её боевой, а среди
двух её маршрутов есть необратимый:

* `unregister_brain_doc` — снимает ключ из манифеста мозга. В её же комментарии:
  «ОДНОСТОРОННЯЯ: вернуть ключ на удалённый файл нельзя». Защита есть (`confirm:true`,
  `folder_id` защищён), но операция становится доступна на боевом URL.
* `move_into_brain` — `moveTo` делает папку Brain **единственным** родителем файла:
  прежняя папка файл теряет.

Опубликовать нашу работу без неё нельзя технически: `redeploy` публикует снимок HEAD
целиком, а чужой код лежит в HEAD с 30.07. Убрать его из выкатки = стереть его из HEAD.
