# Якорь класса «нуль по неразбору»: читатель тика ревизора на VPS (14.08.2026)

**Что закрыто.** Единственный читатель тика ревизора в сводке «статус» (`devbot._revisor_line`,
тема 328) отвечал владельцу «ревизор: тиков ещё не было», не сумев разобрать НИ ОДНОЙ строки
непустого журнала. Класс закрыт контрактом `scan_result.ScanResult` (08.08) и храповиком
`blind_readers` тогда же; ЭТОТ якорь был сознательно оставлен на потом и простоял шесть суток.
Близнец на полосе ПК (`pc_orchestrator`, «7 состояний источника → 3 фразы») закрыт 11.08 коммитом
`1678c4a` — ПК этим заходом не тронут.

| величина | число |

Разбирает 0 при 970 осмотренных — это **красное**, а не «пусто».

**Последний настоящий тик — `2026-08-13 13:26 UTC`** (`NOTE 2026-08-13 13:26 UTC: Orchestrator:
ревизор: 1 окон, чисто`), то есть за **20.6 ч** до замера. Доска же утверждала, что тиков не было
НИ РАЗУ.

## 2. Корень: шаблон держал в голове одно поле без двоеточий

```
прежний : ^NOTE(?:\s+[^:]{0,40})?:\s*ревизор:\s*(.+)
живая   : NOTE 2026-08-13 13:26 UTC: Orchestrator: ревизор: 1 окон, чисто
```

`[^:]` не переходит через двоеточие, а живая строка несёт **штамп времени** (в нём двоеточия) и
автора **после** штампа. Первый `:` после `NOTE` попадает внутрь «13:26» — совпадения нет никогда.
Прежние голдены были зелёными, потому что стояли на ВЫДУМАННОЙ строке `NOTE Orchestrator: ревизор:
2 окон…` — идеализированная фикстура и спрятала дефект (правило §8 рамки: проверка повторяет живой
формат).

## 3. Что сделано

**(а) Контракт.** `devbot._revisor_scan` возвращает `scan_result.ScanResult`: осмотрено (непустые
строки) / разобрано (тики) + исход, payload — самый свежий тик. `_revisor_line` только рендерит.

| исход | когда | что видит владелец |
|---|---|---|
| `ok` | тик разобран | `👁 надзор: ревизор 2026-08-13 13:26 — окон 1` |
| `empty` | строк 0 | `👁 надзор: ревизор: тиков ещё не было — осмотрено 0 строк журнала — источник пуст` |
| `mismatch` | строки есть, тиков 0 | `👁 надзор: ⚠️ тик ревизора НЕ РАЗОБРАН — осмотрено N строк журнала, разобрано 0 — шаблон разошёлся с источником (…)` |
| `unreadable` | журнал не прочитан | `👁 надзор: cowork_log НЕДОСТУПЕН, тик ревизора неизвестен — осмотреть не удалось: источник не прочитан (…)` |

Три НЕ-ok состояния звучат по-разному и ни одно не сворачивается в другое (голден сравнивает три
строки на неравенство). Внутри `mismatch` `detail` РАЗЛИЧАЕТ две беды: «строк со словом „ревизор“
N — тик-шаблон не совпал ни с одной» против «слова „ревизор“ нет ни в одной строке журнала».
Вердикт в обоих случаях громкий намеренно: отличить «событий не было» от «не узнал события» одним
шаблоном НЕЛЬЗЯ, а молчание уже стоило шести суток. Знаменатель у `unreadable` — `None`, а не 0:
отсутствие измерения не записывается нулём.

**(б) Шаблон — по ПОЗИЦИИ, а не по совпадению.** `^NOTE\b(?P<head>.{0,80}?)\bревизор:\s*(?P<body>.+)$`:
тик ОБЪЯВЛЯЕТСЯ в начале строки, сразу за штампом и автором (то же правило позиции, что у маркера
NEEDS_APPROVAL `5ca761d` и у литерала `40c8425`). Голова ограничена 80 символами — на живом журнале
это ловит **37 строк и НИ ОДНОЙ прозаической** из 70, где слово «ревизор» встречается (проверено
поимённо: «…· Ревизор исхода находки…», «ARTIFACT … читатель тика ревизора…» — мимо).
Время берётся из ГОЛОВЫ строки (там штамп), с откатом на тело — легаси-формат ПК без штампа
читается по-прежнему.

## 6. Границы и остатки

* **Ревизор и его проверки не тронуты** — правка живёт только в читателе надзора на VPS;
  полоса ПК не тронута (её близнец закрыт 11.08).
* **Контракт и храповик не изменены ни на строку**; `blind_readers`: слепых читателей **72**, без
  прироста (читатель возвращает `ScanResult`, пустого возврата из ветки промаха у него нет).
* **Молчание ревизора этим заходом не наблюдается**: доска честно показывает дату последнего тика,
  но «тик молчит N часов» никого не будит — это ожидание О-ПК-3, оно по-прежнему не поднято
  (точка касания `expectations._o4`, порог 16 ч на след ПК ловит соседний факт, а не тик).
* Вердикт `mismatch` при подрезанном журнале (тики выпали из окна prune) прозвучит громко, хотя
  тиков в нём и правда нет — цена названа: лишняя строка, а не молчание; `detail` говорит, что
  слова «ревизор» в журнале нет вовсе.
* **Класс «фикс в git ≠ фикс в проде» ДЕЙСТВУЕТ**: `devbot` живёт внутри процесса `bot.py`,
  доставка = рестарт сервиса `splinter`.
