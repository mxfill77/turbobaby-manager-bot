Продолжаем TurboBaby. Внутренний контур (Splinter: учёт / ТО / обслуживание / аудитор / автономия) готов, в проде и функционально подтверждён на живых байках.

**ЧТО РАБОТАЕТ (система ТО/обслуживания — построена и обкатана):**
- **Закрытие масла:** «заменили масло» + фото пробега → сторож B (пробег не убывает) → вопрос кнопкой → «да» доверенного (Пым/владелец) → `set_fleet_oil` в Лист1 кол.I, снят закреп.
- **Регламенты J/K/L** (gear/ABS/возд.фильтр): запись по типу работы (`_classify_work`) + расчёт срока (`next_km`, зеркало масла) + напоминания. Интервалы бот читает из `knowledge_base` (блок `SERVICE_INTERVALS`) через `read_doc`, фоллбэк — хардкод.
- **Карточка байка по запросу** («инфа/статус/что по байку» → `_is_status_request` → `_build_bike_card`): собирается из ЧИТАЕМЫХ источников (find_bike + service_list + история «события» через `read_events`), ничего не пишет.
- **Единая сводка ТО-цикла:** одно итоговое сообщение (работы буллетами, тайский список `_WORK_TH`, закреп итога) вместо разнесённых реплик.
- **Двуязычие:** 🇹🇭 чистый тайский / 🇷🇺 чистый русский, единый разделитель блоков централизованно в `_send`; служебные тоже двуязычные.
- **«События»** (инфо-работы без интервала: масл.фильтр/колодки/цепь/вилка) — отдельный регистр-сноска; `delete_event` чистит по точному ключу.

СЛЕДУЮЩЕЕ = клиентская интеграция: сначала Telegram userbot (от @turbophuket, старт на ПК Пхукет, полуавтомат-черновики, потом Raspberry Pi 24/7), затем WhatsApp Cloud API. Язык RU+EN без тайского, база = turbobaby_faq_v1.md. Первый шаг — движок ответов по FAQ.

   `--push-always` — пуш всегда (тест/расписание); `⚠️` (ошибки в логе при живом боте) пушем НЕ
   дёргает. Ретрай `ping` ×3 — чтобы транзиентный таймаут Bridge не будил ложной тревогой.
   Авто-проверка: systemd timer `splinter-health.timer` (+`.service`) — зовёт `health.py --push`

## Что это
AI-команда ботов для TurboBaby (премиум аренда мотобайков, Пхукет, владелец Филипп, 38 байков). Владелец — не программист, работает на Windows (VS Code + Python 3.12 + Node.js). Рабочие папки на ПК: `D:\turbobaby-bot\` (userbot-скрипты) и `D:\turbobaby-bot\manager-bot\` (бот Splinter).

## Архитектура (готово и работает)
- **Apps Script Bridge** (Web App) — мост к Google Sheets. Деплоится в Apps Script. GET: ping/fleet/clients/anomalies/daily_pulse. POST: транзакции, баланс, обслуживание (ТО), важное, аудит. URL и токен — в .env бота.
- **Splinter** (manager-bot, Python) — внутренний бот-супервайзер в Telegram. Работает в HQ + 5 операционных группах (касса, обслуживание-форум-с-темами, доставка, отметки). Двуязычный RU+TH (в группах есть тайцы). Модель claude-sonnet-4-5.
- **memory.db** (SQLite) — память: правила, заметки, история диалогов (изолирована по chat_id+topic_id).
- **Auditor** (auditor.py) — надзорный модуль: сверяет действия бота с фактами (БД/KB), ловит галлюцинации, нарушения правил, ошибки логики, смешение языков. Журнал — лист `аудит`. Отчёт в HQ 09:30 + команда /audit. Сам не правит — только флаги + предложения, применяются после апрува Филиппа.
